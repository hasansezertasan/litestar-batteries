## Objective

Add `SecureHeadersPlugin(InitPlugin)`, export it and `SecureHeadersConfig` from the subpackage and the top-level package, and prove with real app tests that headers land on 200, 404, 405 and 500 responses and on the OpenAPI UI, while user `before_send` hooks keep working.

## Context

Spec decisions D4, D8, F-1, F-2, F-5, F-7, R-1, R-3. Mirror `src/litestar_batteries/idempotency/plugin.py`: `__init__(config | None = None)` storing `self.config`, sync `on_app_init(app_config)` decorated `@override`, Google-style docstrings. `AppConfig.before_send` is `list[BeforeMessageSendHookHandler]`. Research F4 shows route-level middleware would miss 404/405; these tests lock that behavior in.

## Steps

1. Add failing integration tests using `litestar.testing.create_test_client` and `SecureHeadersPlugin` imported from `litestar_batteries` (this import fails first):
   - Default plugin, `GET /ok` -> 200 with all default headers; `http` base URL has no `strict-transport-security`, a `base_url="https://testserver.local"` client has it.
   - Unknown path -> 404 and wrong method -> 405 both carry the default headers (regression guard for research F4).
   - Handler raising an unhandled exception -> 500 carries the headers.
   - Handler returning `Response(..., headers={"Content-Security-Policy": "custom"})`: default keeps `custom`; `SecureHeadersConfig(override=True)` replaces it.
   - `SecureHeadersConfig(frame_options=None, referrer_policy="no-referrer")` per-field overrides.
   - A user `before_send` hook registered on the app still runs (it stamps a marker header) alongside the plugin.
   - `GET /schema/swagger` (default `OpenAPIConfig`) returns 200 with the default headers and the default CSP does not contain `script-src`/`default-src`.
   - A plain `Litestar` app without the plugin has none of the headers (NF-5).
2. Run them and confirm they fail with `ImportError` for `SecureHeadersPlugin`.
3. Create `src/litestar_batteries/secure_headers/plugin.py` (`__all__ = ["SecureHeadersPlugin"]`): `on_app_init` sets `app_config.before_send = [*app_config.before_send, build_before_send(self.config)]` and returns `app_config`.
4. Update `src/litestar_batteries/secure_headers/__init__.py` to export `SecureHeadersConfig` and `SecureHeadersPlugin`; update `src/litestar_batteries/__init__.py` imports and the sorted `__all__` list.
5. Run verification, then the R-3 check: `uv run --isolated --with 'litestar==2.0.0' pytest tests/test_secure_headers.py`; record the result in Notes. If it fails, raise the `litestar` lower bound in `pyproject.toml` to the lowest passing release (note it for the PR).
6. Commit: `feat(secure-headers): add SecureHeadersPlugin`.
