## Objective

Implement `build_before_send(config)` returning an async `before_send` hook that adds the configured security headers to `http.response.start` messages with handler-wins precedence, HTTPS-only HSTS and no effect on any other message.

## Context

Spec decisions D1, D3, D4, F-3, F-4, F-5. Research F5/F9: `MutableScopeHeaders.from_message(message)` supports `setdefault(name, value)` and `__setitem__`; names are lowercased and latin-1 encoded for you. A Litestar `before_send` hook has the signature `async def hook(message: Message, scope: Scope) -> None`. Headers are precomputed once in `build_before_send` (not per request) to meet NF-2. `hooks.py` must not import any sibling battery.

## Steps

1. Add failing tests to `tests/test_secure_headers.py` that call the hook directly with hand-built ASGI messages and scopes (no app needed):
   - `http.response.start` with empty headers -> every static default header added with the right value.
   - Hand-built messages must include `"headers": []` (`from_message` raises without it). Handler-set header (`content-security-policy: custom`, supplied in mixed case `Content-Security-Policy`) is left unchanged with `override=False` and replaced with `override=True`.
   - HSTS: scope `{"type": "http", "scheme": "https"}` -> `strict-transport-security: max-age=31536000`; scheme `http` -> absent; non-`https` schemes get no HSTS; `hsts_max_age=None` -> absent even on https; includeSubDomains/preload directives render.
   - `http.response.body` and `websocket.accept` messages are not modified (assert the message dict is unchanged).
   - Disabled fields (`None`) never appear.
2. Run them; confirm they fail with `ImportError`/`AttributeError` for the missing `hooks` module.
3. Create `src/litestar_batteries/secure_headers/hooks.py` with `__all__ = ["build_before_send"]`: precompute `static = config.response_headers()` and `hsts = config.hsts_value()` once; the inner hook returns early unless `message["type"] == "http.response.start"`; builds `headers = MutableScopeHeaders.from_message(message)`; writes via a small helper `_apply(headers, items, override)` (override -> `headers[name] = value`, else `headers.setdefault(name, value)`); adds HSTS only when `hsts` and `scope.get("scheme") == "https"`. Keep each function at complexity <= 5; type with `Message`/`Scope` under `TYPE_CHECKING`.
4. Run verification; commit: `feat(secure-headers): add before_send hook`.

## Acceptance Criteria

- [x] Handler-set headers survive by default and are replaced only with `override=True`, case-insensitively.
- [x] HSTS appears only for `https` scheme and only when `hsts_max_age` is not `None`.
- [x] Non-`http.response.start` messages are never mutated.
- [x] Headers are computed once per hook build, not per message.
